# JS Mini Apps

A collection of small front-end and Node.js projects built for practice. It coveres vanilla JS DOM manipulation, browser extensions, API fetch calls, and a basic Node HTTP server.

## Projects

###  Calculator (`Calculatore/`)
A simple calculator supporting add, subtract, multiply, and divide.

---

###  Blackjack (`casino (Black Jack)/`)
A browser-based Blackjack game — start a round, draw cards, and track your chip balance.

---

###  Which Book Character Are You? (`characterguess/`)
A personality-quiz style game ("The Literary Mirror") that matches your answers to a book character.

---

###  Leads Tracker — Chrome Extension (`extension/`)
A Chrome extension (Manifest V3) for saving notes and tabs as quick "leads," with delete-all support.


**To load it locally:** open `chrome://extensions`, enable Developer Mode, click "Load unpacked," and select the `extension/` folder.

---

###  Passenger Counter (`pessanger counter/`)
A simple tally counter for tracking how many people have entered, with a save/history feature.


---

###  Weather App (`weather app/`)
Look up current weather by city name, powered by the OpenWeatherMap API.


---

###  API Practice (`api/`)
Scratch space for practicing `fetch()`, async/await, and image preloading against a few public demo APIs.

---

###  Travel Destination API (`Node_js/`)
A Node.js HTTP server (built without Express) that serves travel-destination data and supports query-param filtering.

**Run it:**
```bash
cd Node_js
npm install
npm start
```

## Getting Started

Most projects are plain HTML/CSS/JS — just open the relevant `.html` file in a browser. Exceptions:
- **`extension/`** — load as an unpacked Chrome extension (see above)
- **`Node_js/`** — run with Node (see above)
